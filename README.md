# Nova — Responsive Landing Page
### Yuva Intern | Week 1 Task

A responsive landing page created with semantic HTML5, modern CSS, Flexbox/Grid, media queries, and vanilla JavaScript.

## Files
- `index.html` — semantic page structure
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation interaction

## Features
- Responsive desktop, tablet and mobile layouts
- Semantic HTML5 sections
- CSS Grid and Flexbox
- Mobile navigation toggle
- Smooth scrolling
- Accessible navigation button with ARIA state
- Hover interactions
- No external frameworks or dependencies

## How to run
Open `index.html` in any modern browser.

## Suggested testing
Test at approximately:
- Desktop: 1440px
- Tablet: 768px
- Mobile: 375px

The page is intentionally framework-free so the core HTML, CSS and JavaScript implementation is easy to review.
